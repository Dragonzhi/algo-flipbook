# 101. 对称二叉树

| 项 | 内容 |

## 1. 题意

给你一个二叉树的根节点 `root`，检查它是否轴对称。

### 示例 1

```
输入：root = [1,2,2,3,4,4,3]
输出：true
```

### 示例 2

```
输入：root = [1,2,2,null,3,null,3]
输出：false
```

### 提示

- 树中节点数目在范围 `[1, 1000]` 内
- `-100 <= Node.val <= 100`

### 进阶

你可以运用递归和迭代两种方法解决这个问题吗？

## 2. 思路：递归镜像

**先说清楚「对称」到底要求什么。** 很多人第一反应是「左子树和右子树长得一样」，这不对。

对称要求的是**互为镜像**：把右子树整体翻过来，应该和左子树完全重合。翻译成节点配对就是：

| 左子树这边 | 配 | 右子树那边 |
| --- | --- | --- |
| 左子树的**左**孩子 | ↔ | 右子树的**右**孩子 |
| 左子树的**右**孩子 | ↔ | 右子树的**左**孩子 |

所以比较函数必须**同时拿着两个节点**走，而不是分别遍历两棵树再比结果。

### 递归三要素

1. **终止条件**（按这个顺序判，顺序不能反）：
   - 两个都空 → 这一对成立，返回 `true`。
   - 只有一个空 → 一边有节点一边没有，镜像断了，返回 `false`。
   - 两个都不空但值不同 → 返回 `false`。
2. **单层逻辑**：值相等还不够，要接着比**外侧**（左.左 ↔ 右.右）和**内侧**（左.右 ↔ 右.左）。
3. **返回值**：两个子问题都用 `&&` 串起来，任何一个假，整体就假。

### 为什么不能「中序遍历比一下」

一个常见的错误解法是：分别中序遍历两棵树，看结果是否相同。这是**必要但不充分**的。
反例：一棵树根为 1，左孩子 2、右孩子 2，但左孩子的右孩子是 2 —— 中序序列可以相同，
镜像关系却不成立。镜像约束的是**位置**，不是**值的集合**，遍历顺序丢掉了位置信息。

## 3. 手动推演

### 示例 1（对称，`true`）

`root = [1,2,2,3,4,4,3]`，记左子树根为 `L`、右子树根为 `R`。

| 次序 | 比较对象 | 判断 | 结果 | 下一步 |
| --- | --- | --- | --- | --- |
| 1 | `L(2)` vs `R(2)` | 值相等 | 继续 | 先比外侧 |
| 2 | `L.左(3)` vs `R.右(3)` | 值相等 | 继续 | 再比它们的孩子 |
| 3 | `3` 的两个孩子 | 都为空 | `true` | 这条支路结束 |
| 4 | `L.右(4)` vs `R.左(4)` | 值相等 | 继续 | 比它们的孩子 |
| 5 | `4` 的两个孩子 | 都为空 | `true` | 这条支路结束 |
| 6 | 全部成立 | — | **`true`** | 返回 |

注意次序：**外侧先比，内侧后比**，因为代码是 `check(left->left, right->right) && check(left->right, right->left)`，`&&` 从左往右求值。

### 示例 2（不对称，`false`）

`root = [1,2,2,null,3,null,3]`，展开成树是：

```
        1
      /   \
     2     2
      \     \
       3     3
```

| 次序 | 比较对象 | 判断 | 结果 |
| --- | --- | --- | --- |
| 1 | `L(2)` vs `R(2)` | 值相等 | 继续 |
| 2 | `L.左(空)` vs `R.右(3)` | 一边空一边有值 | **`false`** |

第 2 步就失败了：左边这个位置是空的，右边却有个 `3`，镜像对不上。`&&` 短路，后面的
`L.右` vs `R.左` 根本不会被求值——这就是为什么演示里那条支路一直是灰色的。

## 4. 代码

```cpp
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        return !root || check(root->left, root->right);
    }

    bool check (TreeNode* left, TreeNode* right) {
        if (!left && !right) return true;
        if (!left || !right) return false;
        return left->val == right->val 
            && check(left->left, right->right)
            && check(left->right, right->left);
    }
};
```

## 5. 边界与易错点

1. **函数签名必须是两参数**。写成 `check(root->left)` 这种单参数版本，一开始就走偏了——
   镜像约束天生是「一对节点」之间的关系。
2. **三个终止条件的顺序不能反**。必须「都空 → 一个空 → 值不等」，先判一个空之前要保证
   两个都非空，否则 `left->val` 会解引用空指针。
3. **外侧 / 内侧别写反**。正确的是 `check(left->left, right->right)` 配
   `check(left->right, right->left)`；写成 `check(left->left, right->left)` 就退化成
   「两棵子树长得一样」了。
4. **`&&` 的短路是有意义的**，不是可选的优化：只要一条支路假，整体就假，剩下的不必再算。
   演示里点击「播放」能看到失败后立刻跳到结论。
5. **空树算对称**。`!root ||` 这个短路必须有，`root` 为空时直接返回 `true`。
6. **别用「中序遍历结果相同」判对称**，理由见 §2 末尾。
7. **递归深度是 `O(h)`**，链状树（每个节点只有一个孩子）会退化成 `O(n)` 的栈深度。
8. **迭代写法**：用队列**成对**入队，每次弹两个节点比较，再按镜像顺序压入四个孩子
   （左.左、右.右、左.右、右.左）；注意空孩子也要入队占位，否则配对会错位。
