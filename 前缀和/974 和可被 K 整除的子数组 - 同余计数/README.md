## 1. 题意

给定一个整数数组 `nums` 和一个整数 `k`，返回其中元素之和可被 `k` 整除的非空**子数组**的数目。

**子数组**是数组中**连续**的部分。

### 示例

**示例 1：**

```
输入：nums = [4,5,0,-2,-3,1], k = 5
输出：7
解释：
有 7 个子数组满足其元素之和可被 k = 5 整除：
[4,5,0,-2,-3,1], [5], [5,0], [5,0,-2,-3], [0], [0,-2,-3], [-2,-3]
```

**示例 2：**

```
输入：nums = [5], k = 9
输出：0
```

### 提示

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `2 <= k <= 10^4`

## 2. 思路：前缀和 + 同余

先约定：`S[0] = 0`，`S[i] = nums[0] + … + nums[i-1]` 表示**前 i 个数**的和。那么子数组 `nums[l..r]` 的和是

```
S[r + 1] - S[l]
```

它能不能被 `k` 整除？看同余：

```
S[r+1] - S[l] ≡ 0 (mod k)   ⇔   S[r+1] ≡ S[l] (mod k)
```

**两个前缀和余数相同，夹在中间的这段就一定被 `k` 整除。** 于是问题从「枚举 O(n²) 个子数组」变成「数一数每个余数出现了几次」：同为余数 `r` 的 `m` 个前缀，两两配对就是 `C(m, 2)` 个合法子数组。

边扫边算，不需要存下所有前缀和：

1. `cnt[0] = 1`：空前缀 `S[0] = 0` 先记一次，它负责「从下标 0 开始」的那些子数组。
2. 每读一个数：`cur += x`，取余 `r`。
3. `count += cnt[r]`：之前余数同为 `r` 的每个前缀，和当前前缀配成一对。
4. `cnt[r]++`：把当前前缀也记进去，留给后面配对。

**顺序不能反**：先查后加，保证只和「之前」的前缀配对，不会把一个空区间当成子数组。

### 负数取模为什么要修正

C++ 的 `%` 向零取整，`-1 % 5 == -1`，不是 `4`。如果直接拿 `-1` 当桶下标，`vector` 会越界；就算用哈希表，`-1` 和 `4` 也会被当成两个不同的键，漏掉配对。

```cpp
int r = ((cur % k) + k) % k;   // 先 % 得 [-k+1, k-1]，再加 k 得正，再 % 一次落回 [0, k-1]
```

### 为什么 int 够用

- `cur`：`|nums[i]| ≤ 10^4`、`n ≤ 3 * 10^4`，绝对值最大 `3 * 10^8`，在 `int` 范围内。
- `count`：最多 `n(n+1)/2 ≈ 4.5 * 10^8` 对，也在 `int` 范围内（想要更稳可以用 `long long`）。

## 3. 手动推演（示例 1）

`nums = [4,5,0,-2,-3,1]`，`k = 5`，初始 `count = 0, cur = 0, cnt[0] = 1`。

| 步 | i | nums[i] | cur | r = cur % 5 | 命中 cnt[r] | count | 操作后 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 初始化 | — | — | 0 | — | — | 0 | `cnt[0] = 1` |
| 1 | 0 | 4 | 4 | 4 | 0 | 0 | `cnt[4] = 1` |
| 2 | 1 | 5 | 9 | 4 | 1 | 1 | `cnt[4] = 2` |
| 3 | 2 | 0 | 9 | 4 | 2 | 3 | `cnt[4] = 3` |
| 4 | 3 | -2 | 7 | 2 | 0 | 3 | `cnt[2] = 1` |
| 5 | 4 | -3 | 4 | 4 | 3 | 6 | `cnt[4] = 4` |
| 6 | 5 | 1 | 5 | 0 | 1 | 7 | `cnt[0] = 2` |

第 2、3、5 步都在「收集同余前缀」：余数 4 依次攒到 1、2、3 个，答案按 `1 + 2 + 3` 累加。

换个角度，把前缀按余数分组：

| 前缀位置 | 0（空） | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 前缀和 `S` | 0 | 4 | 9 | 9 | 7 | 4 | 5 |
| `S % 5` | 0 | 4 | 4 | 4 | 2 | 4 | 0 |

- 余数 4 出现 4 次 → `C(4,2) = 6` 对；
- 余数 0 出现 2 次 → `C(2,2) = 1` 对；
- 合计 `6 + 1 = 7`，与答案一致。

## 4. 代码

```cpp
class Solution {
public:
    int subarraysDivByK(vector<int>& nums, int k) {
        int count = 0, cur = 0;
        vector<int> cnt(k, 0);
        cnt[0] = 1;
        for (int x : nums) {
            cur += x;
            int r = ((cur % k) + k) % k;
            count += cnt[r];
            cnt[r]++;
        }
        return count;
    }
};
```

## 5. 边界与易错点

1. **`cnt[0] = 1` 必须在循环之前**：它代表空前缀，少了它，所有「从下标 0 开始」的合法子数组都会漏掉。
2. **负数必须归一到 `[0, k-1]`**：`((cur % k) + k) % k`。直接 `cur % k` 可能得到负下标（越界）或负键（配对失败）。
3. **先 `count += cnt[r]`，再 `cnt[r]++`**：反了就把当前前缀自己算进去，答案偏大。
4. **子数组非空**由「只和之前的前缀配对」保证，不需要额外判断，也不要把空区间算进去。
5. **暴力是 `O(n²)`**：`n = 3 * 10^4` 时约 `9 * 10^8` 次加法，必然超时。
6. **`k` 最大 `10^4`**：开 `vector<int> cnt(k)` 没问题；若用哈希表，空间是 `O(min(n, k))`，本题用定长数组更快。
7. **`% k` 与 `+ k` 的括号**不要省：`cur % k + k % k` 是另一回事（虽然本题里 `k % k == 0`，但习惯要写对）。
